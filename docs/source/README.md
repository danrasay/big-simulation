# Source material

These files are the course project this app is built from:

> Goldblatt, Luna Y.; Branco Chaves, João; Landman, Andrew M.; Mwinjuma, Salmin B.; and Vitelli, Braden C., "Financial Statement Analysis Project: 'The Big Simulation'" (2022). Open Educational Resources. 13. https://cupola.gettysburg.edu/oer/13

The project is licensed under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). The originals (Word, RTF and PDF files) can be downloaded from the link above.

## What changed in conversion

- The text was extracted from the original files and saved as Markdown. Page layout is not preserved.
- The originals highlight the passages most relevant to each role. That highlighting did not survive extraction.
- Exhibit 4 came from an RTF file and is kept as tab-separated plain text.
- No figures were changed. The figures used by the app are transcribed separately into `scenarios/`, where each one cites the exhibit table it came from.

The instructor manual from the same project is not in this repository.
